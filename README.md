## 这是什么

一份对 QCon26 上海站公开分享材料的内容质量分析：按自定的八维指标，对 75 份材料逐份打分并给出评语与改进建议。评估日期 2026-10-28，方案版本 v1.1（已按企业审核 / 脱敏约束校准）。

本分析仅评**材料中可见的内容**——问题定义、机制讲解、验证设计、推理链、取舍与可迁移经验；不评现场表达、演讲感染力或视频效果。所有生产指标均标为讲者材料自述，未做日志 / 代码 / 实验复现。详细局限见报告第八节。

## 如何解读分数

- 评分维度：问题与受众 (A)、机制 (C)、验证设计 (D)、效果证据 (E)、推理与取舍 (T)、可迁移性 (M)、结构 (S)、表达克制 (X)。权重见 `评价方案.md`。
- 企业审核导致未公开的数值、样本、时间、成本**不扣分**；信息限制到无法判断时记 N/A（CSV 为空、JSON 为 null），按剩余维度已评权重归一，`assessed_weight` 表示已评覆盖。
- 覆盖率不同的分数**不直接做严格排名**，只在相同覆盖组内解释。
- 公开效果可观察性是独立非计分字段，不代表技术水平。
